KASYA FRÈRES — site vitrine statique
1. Déployer ce dossier ou le ZIP avec Vercel Drop.
2. Une fois le domaine choisi, remplacer YOUR-DOMAIN dans robots.txt et sitemap.xml par le domaine réel.
3. Dans Google Search Console, ajouter le domaine, vérifier la propriété et soumettre /sitemap.xml.
4. Les images des références sont des visuels d'illustration générés, clairement signalés sur le site.
